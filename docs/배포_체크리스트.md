# 배포 체크리스트

운영 서버에 손님·관리자 Streamlit 화면과 FastAPI 서버를 배포할 때 확인한다. 배포 환경마다 도메인, 포트, 환경 변수 이름이 다를 수 있으므로 실제 배포 플랫폼 설정과 함께 확인한다.

## Streamlit 설정

- [ ] `.streamlit/config.production.toml`의 `[browser] serverAddress`를 실제 접속 도메인으로 바꾼다. `your-server.com`은 예시값이므로 그대로 배포하지 않는다.
- [ ] `[browser] serverPort`를 사용자가 브라우저에서 접속하는 외부 포트에 맞춘다. HTTPS를 프록시나 로드밸런서에서 처리하면 보통 `443`이다.
- [ ] `[server] port`를 배포 플랫폼이 앱에 할당한 내부 포트에 맞춘다. 플랫폼이 `PORT` 환경 변수로 포트를 제공하면 그 방식에 맞춰 실행한다.
- [ ] `[server] address`는 서버 외부 접속이 필요한 배포에서 `0.0.0.0`으로 둔다.
- [ ] 운영 설정 파일을 Streamlit이 읽는 `.streamlit/config.toml` 위치에 제공한다. 현재 저장소 파일은 `config.production.toml`이라는 이름이므로, 배포 과정에서 `.streamlit/config.toml`로 복사하거나 이름을 바꾼다.
- [ ] 설정을 바꾼 뒤 Streamlit 프로세스를 재시작하고, 사용자 화면과 관리자 화면이 공개 도메인의 HTTPS 주소에서 열리는지 확인한다.

> Streamlit은 프로젝트 설정 파일로 실행 기준 디렉터리의 `.streamlit/config.toml`을 읽는다. 설정 방식과 적용 우선순위는 [Streamlit 설정 문서](https://docs.streamlit.io/develop/api-reference/configuration/config.toml)를 참고한다.

## 서버와 환경 변수

- [ ] FastAPI 서버가 운영 환경에서 실행되고, 공개할 API 주소가 정해져 있는지 확인한다.
- [ ] 프론트엔드가 호출하는 API 주소가 운영 서버 주소를 가리키는지 확인한다.
- [ ] 운영용 비밀 값과 연결 정보는 배포 플랫폼의 환경 변수 또는 비밀 저장소에 등록한다. `.env` 파일이나 비밀 값을 저장소에 올리지 않는다.
- [ ] 운영 환경이 개발용 로그인 우회나 모의 회원 동작을 사용하지 않는지 확인한다.
- [ ] 데이터베이스 연결 대상이 운영 DB인지, 필요한 테이블과 초기 데이터가 준비됐는지 확인한다.
- [ ] HTTPS 연결과 도메인 인증서가 정상인지 확인한다. 자체 호스팅은 보통 리버스 프록시나 로드밸런서에서 HTTPS를 처리한다.

## 배포 후 확인

- [ ] 사용자 화면과 관리자 화면이 각각 정상적으로 열린다.
- [ ] 화면에서 백엔드 API 요청이 성공하고 브라우저 콘솔 및 서버 로그에 연결 오류가 없는지 확인한다.
- [ ] 로그인, 메뉴 조회, 주문 등 실제 배포 범위의 주요 흐름을 확인한다.
- [ ] 오류 화면에 내부 상세 정보나 비밀 값이 노출되지 않는지 확인한다.
- [ ] 배포에 사용한 설정 파일과 환경 변수가 저장소에 비밀 값 없이 반영됐는지 확인한다.
